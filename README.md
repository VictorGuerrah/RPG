# RPG

Repositório principal do projeto de RPG e do Card Collection.

## Estrutura

- `card-collection/` — interface web do compêndio de cartas.
- `rules/system_rules.md` — regras do sistema em Markdown.

O conteúdo dinâmico das cartas e as regras publicadas são armazenados no Supabase; este repositório mantém o código e uma cópia versionada das regras.
